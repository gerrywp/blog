### 库介绍
1. wails2-Go的快并且轻量的Electron 替代品。您可以使用 Go 的灵活性和强大功能，结合丰富的现代前端，轻松的构建应用程序。
2. svelte-是一个新兴热门的前端框架，在最新的《State of JS survey of 2020》中，它被预测为未来十年可能取代React和Vue等其他框架的新兴技术。
3. sveltekit-是一个框架，用于使用Svelte快速开发健壮、高性能的 Web 应用程序。如果您来自 React，SvelteKit 类似于 Next。如果您来自 Vue，SvelteKit 类似于 Nuxt。是个开箱即用的框架，包含了路由，热加载，SPA等功能。
4. skeleton-是一个为 Svelte 和 Tailwind CSS 打造的现代化UI工具包。类似于(vue的ElementUI,react的and design pro)
5. tailwindcss-是一个利用公用程序类（Utilize Class，下文皆称Utilize Class）的 CSS 框架。
6. vite-新型前端构建工具(听说比webpack简单，webpack确实配置太难了)

> 1. [sveltekit](https://svelte.dev/docs/kit/introduction)
> 2. [skeleton](https://www.skeleton.dev/docs/svelte/get-started/installation)

### 踩坑记录
**结论：** 不能使用sveltekit2框架，因为它是开箱即用的web应用框架。使用它的路由功能（属于服务器端路由），它所使用的SSR（Server Sider Render）服务器端渲染需要有Nodejs环境。
但是Wails开发的客户端是纯的浏览器环境，是无法运行的。因此当你使用`wails dev`启动调试的时候，默认在后台启动了一个Nodejs环境，可以使用浏览器调试你的页面样式，程序能正常启动。
但是当使用`wails build`打包成exe可执行文件之后，由于缺少Nodejs服务器端渲染，程序是无法启动的。


### 搭建基础框架
1. 安装wails2,可以直接参照官方文档(https://wails.io/zh-Hans/docs/gettingstarted/installation)安装，此处不做详细介绍。当前项目安装的是wails2
2. 使用wails2工具创建项目(sevlte5相较于3有很大改动)
```bash
# 这里我不用-t sevlte指定sevlte框架，直接创建一个空的项目（后续使用npm create vite@latest创建基于sevlte5的模板）
wails init -n myproject
# 默认使用-t sevlte 创建的项目使用的是sevlte3
```
#### 踩坑开始

**备注：** npm和npx的区别，npm 是 Node Package Manager（包管理器），npx 是 Node Package Execute（包执行器）。

npm: 安装管理包，下载并保存在本地

npx: 直接运行包，并不下载保存在本地

**typography (@tailwindcss/typography)**

给富文本、文章、博客内容提供一套美观的默认排版样式
自动处理标题、段落、列表、代码块、引用等 HTML 元素的间距、字体和颜色
适合做内容型网站，不用自己写大量 prose 样式

**forms (@tailwindcss/forms)**

重置浏览器原生表单元素（input、checkbox、radio、select 等）的默认样式
让表单控件在不同浏览器下表现一致，并且更容易用 Tailwind 工具类自定义
适合做需要大量表单的后台管理、登录注册等页面

#### 踩坑结束
3. 直接使用Skeleton框架的**vite+svelte**安装文档即可
```bash
npm create vite@latest
	- Set your project named as desired
	- Set Svelte as the framework
	- Set Typescript as the variant
cd {yourProjectName}
npm install
```
[vite+svelte安装文档](https://www.skeleton.dev/docs/svelte/get-started/installation/vite-svelte)

4. 虽然Sveltejs/kit能通过禁用SSR实现SPA的功能，目前没有研究。再者如果都不需要用Svelte/kit的目录路由功能，个人目前感觉在用该框架意义不大。
可以直接用Svelte搭配一个SPA路由即可`svelte-spa-router`。
```bash
npm i svelte-spa-router
# https://github.com/ItalyPaleAle/svelte-spa-router
```

到这里基本的框架就搭建好了，然后可以参照svelte.dev官网和Skeleton官网配置进行开发了。
