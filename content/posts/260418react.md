### 安装commandlinetools
进入安卓主页，滑动到最底部，下载commandlinetools压缩包。

在C盘根目录下创建android_sdk目录，然后将下载的zip文件解压缩到当前目录下，并设置环境变量。

设置环境变量
```shell
ANDROID_HOME=C:\Android\sdk  #目录千万不能带下划线
#将命令行工具添加到path
path=%ANDROID_HOME%\cmdline-tools\latest\bin;%ANDROID_HOME%\platform-tools
```

> https://developer.android.google.cn/studio?hl=zh-cn#command-line-tools-only

### 使用命令行工具sdkmanager

打开终端，安装必备工具（平台工具、构建工具）：
```shell
# 1. 查看可安装的包
sdkmanager --list

# 2. 安装核心组件 (以 Android 35 为例)
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"
```

**备注：** 也可以不用手动安装，后续在`react native`脚手架创建的项目下，使用`npm run android`命令也会自动安装相关工具（包括NDK）

### 核心工具与常用命令
1. sdkmanager (SDK 管理器)
用于安装、更新、卸载 SDK 组件。
``` bash
sdkmanager --list               # 列出所有已安装和可用的包
sdkmanager "platform-tools"     # 安装平台工具 (含adb)
sdkmanager --update             # 更新所有已安装的包
sdkmanager --uninstall "平台;版本" # 卸载包
```

2. adb (Android 调试桥)
用于电脑与手机 / 模拟器通信，最常用工具。
* 设备连接
```bash
adb devices              # 查看已连接设备
adb connect 设备IP:5555  # 无线连接
```
* 应用管理
```bash
adb install 应用.apk      # 安装APK
adb install -r 应用.apk  # 覆盖安装
adb uninstall 包名        # 卸载应用 (如: com.example.app)
```

### 安卓Mumu模拟器

官方的Android 模拟器，占用资源太多，不用安装，直接安装第三方的Mumu模拟器,启动模拟器
```bash
adb devices # 查看可用设备
adb connect localhost # 链接模拟器(默认5555端口)
adb devices 
adb root # 切换到root权限
adb shell # 进入shell环境
```
> https://mumu.163.com/help/20240807/40912_1086360.html

### 创建react native项目

直接参照react native中文文档即可
```bash
npx @react-native-community/cli init AwesomeProject # 初始化项目
cd AwesomeProject
npm run android # 启动项目，会自动安装gradle,platforms,platform-tools等
```
然后示例apk被安装到了Mumu模拟器上，并已经运行起来了。

**备注**:

### 各种坑
1. 路径千万不能带`_`，比如：`Android_SDK`这样的路径，c++编译的时候会提示找不到.h头文件。
应用程序启动不起来会报各种乱七八糟的错误。
2. 项目路径上带有特殊符号，例如`[.,_,中文]`,编译的时候会报错。

### 团队协作
RN CLI 项目体积巨大，主要是这几类：
1. node_modules/（依赖包）
2. android/.gradle/、android/build/（安卓编译缓存）
3. ios/Pods/、ios/build/（iOS 原生依赖 + 编译产物）
4. 各种日志、临时文件、IDE 配置文件
以上这些文件都是不需要上传到git服务器的，添加**gitignore**文件

```bash
# 典型会被忽略的
node_modules/
android/build/
android/.gradle/
android/app/build/
ios/Pods/
ios/build/
*.log
.DS_Store
```

> https://reactnative.cn/docs/environment-setup
