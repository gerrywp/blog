Claude Code CLI 如日中天，奈何 Opus 模型有额度限制且价格不菲。国产大模型中，智谱 AI（好用）和 DeepSeek（便宜）是首选，其他国产模型暂不推荐。

## 安装 Claude Code CLI

全局安装：

```bash
npm install -g @anthropic-ai/claude-code
```

也可以使用智谱提供的 helper 脚本一键安装：

```bash
npx @z_ai/coding-helper
```

> **参考文档：**
> - [Claude Code 官方文档](https://code.claude.com/docs/zh-CN/overview#terminal)
> - [智谱 AI Coding Plan 文档](https://docs.bigmodel.cn/cn/coding-plan/extension/coding-tool-helper#%E5%91%BD%E4%BB%A4%E5%88%97%E8%A1%A8)

## 手动脚本切换模型

### 1. 智谱 AI 配置脚本 `c-zai.bat`

```batch
@echo off
chcp 65001 >nul
set "ANTHROPIC_AUTH_TOKEN=你购买的智谱api key"
set "ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic"
set "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1"
set "ANTHROPIC_MODEL=glm-4.5-air"
set "ANTHROPIC_DEFAULT_OPUS_MODEL=glm-5.1"
set "ANTHROPIC_DEFAULT_SONNET_MODEL=glm-5.0"
set "ANTHROPIC_DEFAULT_HAIKU_MODEL=glm-4.5-air"
set "CLAUDE_CODE_SUBAGENT_MODEL=glm-4.5-air"
set "CLAUDE_CODE_EFFORT_LEVEL=max"
echo 已切换到智谱环境...
claude
```

### 2. DeepSeek 配置脚本 `c-ds.bat`

```batch
@echo off
chcp 65001 >nul
set "ANTHROPIC_AUTH_TOKEN=你的deepseek购买的api key"
set "ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic"
set "ANTHROPIC_MODEL=deepseek-v4-pro[1m]"
set "ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro[1m]"
set "ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro[1m]"
set "ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash"
set "CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash"
set "CLAUDE_CODE_EFFORT_LEVEL=max"
echo 已切换到 DeepSeek 环境...
claude
```

### 3. 使用方式

将以上脚本放入系统 PATH 环境变量中，后续直接通过脚本名启动：

```bash
# 进入工作目录
cd d:\workspace

# 加载智谱配置
c-zai
# 在新窗口中运行
claude

# 或加载 DeepSeek 配置
c-ds
claude
```

## CC Switch 工具一键切换

如果不想手写脚本，可以使用 `cc switch` 工具快速切换模型。

直接从 GitHub Release 页面下载安装：

> - [CC Switch GitHub](https://github.com/farion1231/cc-switch/releases)

> - [CC Switch 官网](https://ccswitch.ai/zh/)

安装后在图形界面中配置对应的 API Key 和 Base URL 即可。

## Codex 对接国产模型

OpenAI 最近为其 Codex 和 Agents 生态推出了全新的 **Responses** API 协议（端点通常为 /v1/responses），用以替代传统的 **Chat Completions** 协议。而 DeepSeek 的 API 目前高度兼容的是 OpenAI 传统的 Chat Completions 协议（端点为 /v1/chat/completions），尚未跟进支持最新的 Responses 协议。因此，当 Codex 客户端尝试向 DeepSeek 发送 Responses 格式的请求时，DeepSeek 服务器无法识别，从而报错。

要解决这个问题，核心思路是将新协议转换回旧协议，或者绕开新协议。以下是几种可行的解决方案：

1. **自行搭建接口中转**：将 `responses` 协议转换为 `chat/completions` 格式。
2. **使用第三方中转工具**：部分开源项目已提供兼容适配。

## Copilot 接入国产模型

### 第一步：安装插件

- 安装 VS Code 的 **GitHub Copilot** 和 **GitHub Copilot Chat** 基础插件。
- 在扩展商店搜索 **"OAI Compatible Provider for Copilot"**（或缩写 `oai`）并安装。此插件是让 Copilot 识别非官方模型的关键。

### 第二步：获取 API Key

1. 前往 [智谱 AI 开放平台](https://open.bigmodel.cn/) 注册并登录。
2. 点击右上角头像 → **API Keys** → **创建新的 API Key**。
3. 复制生成的 Key 并妥善保存。

### 第三步：配置插件

打开 VS Code 设置（`Ctrl+,`），搜索 `oai`，进入插件设置界面，填写以下信息：

**Base URL（接口地址）：**

| 服务商 | 计费模式 | Base URL |
|--------|----------|----------|
| 智谱 GLM | Coding Plan（包月） | `https://open.bigmodel.cn/api/coding/paas/v4` |
| 智谱 GLM | 按 Token 计费 | `https://open.bigmodel.cn/api/paas/v4` |
| DeepSeek | — | `https://api.deepseek.com/v1` |
| Kimi | — | `https://api.moonshot.cn/v1` |

在 **API Key** 字段中粘贴你的 Key 并回车确认。

### 第四步：启用模型

1. 打开 Copilot Chat 面板（点击顶边栏 Copilot 图标，或快捷键 `Ctrl+I`）。
2. 点击模型选择区域 → **Manage Models**（管理模型）。
3. 在弹出的供应商列表中选择 **[OAI Compatible]**，点击右侧齿轮图标进入详细配置。
4. 输入 API Key 并回车确认。
5. 返回模型列表，勾选想使用的模型（如 **GLM-5.1**），点击 **OK** 保存。
6. 在 Copilot Chat 的模型下拉菜单中将模型切换为 **GLM-5.1**，即可开始使用。
