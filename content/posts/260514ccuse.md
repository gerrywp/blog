Claude Code CLI如日中天，奈何opus模型有限制，并且贵。这里选中智谱AI大模型(好用)和deepseek大模型(便宜),其它国产都是垃圾。

## 安装Claude code CLI

命令行全局安装
```bash
npm install -g @anthropic-ai/claude-code
# 或者使用智谱的helper脚本安装
npx @z_ai/coding-helper
```

> [Claude code官方](https://code.claude.com/docs/zh-CN/overview#terminal)

> [智谱AI文档](https://docs.bigmodel.cn/cn/coding-plan/extension/coding-tool-helper#%E5%91%BD%E4%BB%A4%E5%88%97%E8%A1%A8)

## 手动脚本切换模型

1. 创建命名为`c-zai.bat`的智谱AI大模型配置脚本

```bash
@echo off
chcp 65001 >nul
:: 设置智谱 Anthropic 协议变量
set "ANTHROPIC_API_KEY=你的智谱API_Key"
set "ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/paas/v4"

echo ==============================
echo   已切换到 智谱 GLM 环境
echo   协议: Anthropic
echo   请在此窗口运行 claude --model glm-4-air
echo ==============================

cmd /k
```

2. 创建名为`c-ds.bat`的deepseek大模型配置脚本

```bash
@echo off
chcp 65001 >nul
:: 设置 DeepSeek OpenAI 协议变量
set "OPENAI_API_KEY=你的DeepSeek_API_Key"
set "OPENAI_BASE_URL=https://api.deepseek.com/v1"

echo ==============================
echo   已切换到 DeepSeek 环境
echo   协议: OpenAI
echo   请在此窗口运行 claude --model deepseek-chat
echo ==============================

cmd /k
```

将以上两个脚本放入系统环境变量，后续要用的使用直接使用即可

```bash
# 进入工作目录
cd d:\workspace
# 加载智谱配置
c-zai
# 运行claude 
Claude
# 加载deepseek配置
c-ds
```

## 使用cc switch

个人认为自己写脚本也不是什么难事，如果偷懒可以直接使用cc switch工作做切换。
cc switch工具可以直接在github上release页面直接下载安装。

> [github上的cc](https://github.com/farion1231/cc-switch/releases)

> [cc switch官网](https://ccswitch.ai/zh/)

## Codex工具对接国产模型

使用cc switch是无法做到的，2026年5月最新的open ai协议标准改成了**wire="responses"**，国产的大模型都尚未适配新的接口标准，还是使用的老的标准
**wire="chat"**(对应的还是使用open ai兼容模式的URL地址：`chat/completions`)。
所以暂时放弃使用Codex了，因为自己要做接口中转，也可以使用第三方工具。

## copilot接入国产模型

📦第一步：环境准备与插件安装

安装基础插件：确保您已安装VSCode的 “GitHub Copilot” 和 “GitHub Copilot Chat” 插件。

安装关键插件：在VSCode扩展商店中搜索 “OAI Compatible Provider for Copilot”（或缩写 oai）并安装。此插件是让Copilot识别非官方模型的关键

获取API Key：

前往智谱AI开放平台注册并登录

点击右上角头像 → “API Keys” → “+ 创建新的API Key”

复制生成的API Key并妥善保存

⚙️ 第二步：在VSCode中配置插件

打开VSCode设置（快捷键 Ctrl+, 或 Cmd+,），在搜索框输入 oai，打开该插件的设置界面

填写Base URL（接口地址），这是最关键的配置。根据您选择的计费模式，地址不同

智谱GLM Coding Plan（包月计划）：https://open.bigmodel.cn/api/coding/paas/v4

智谱按Token消耗计费：https://open.bigmodel.cn/api/paas/v4

DeepSeek：https://api.deepseek.com/v1

Kimi：https://api.moonshot.cn/v1

在设置中找到 “API Key” 或类似字段，粘贴您在第一步获取的智谱API Key

🚀 第三步：在Copilot中启用并使用GLM-5模型

打开Copilot Chat面板（点击VSCode顶边栏的Copilot图标，或使用快捷键 Ctrl+I）

点击模型选择区域，打开模型列表，然后点击 “Manage Models”（管理模型）按钮

在弹出的供应商列表中，选择 “[OAI Compatible]”，然后点击其右侧的小齿轮图标进入详细配置

在配置窗口中输入您的API Key并回车确认

返回模型列表，此时应该能看到可用的模型（如 “GLM-5.1”），勾选您想使用的模型，然后点击 “OK” 保存配置

最后，在Copilot Chat的模型选择下拉菜单中，将模型切换为 “GLM-5.1”，即可开始使用
