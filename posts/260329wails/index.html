技术方案：wails2,svelte5.55.0,sveltekit2.55.0,skeleton4.13.0,tailwindcss4.2.2,vite7.3.1

使用wails2的sveltekit开发企业级windows客户端，开发效率直接拉满，因为有cline+volcengine+vscode(彻底抛弃微软笨重的vs2026啦)

库介绍#

  1. wails2-Go的快并且轻量的Electron 替代品。您可以使用 Go 的灵活性和强大功能，结合丰富的现代前端，轻松的构建应用程序。
  2. svelte-是一个新兴热门的前端框架，在最新的《State of JS survey of 2020》中，它被预测为未来十年可能取代React和Vue等其他框架的新兴技术。
  3. sveltekit-是一个框架，用于使用Svelte快速开发健壮、高性能的 Web 应用程序。如果您来自 React，SvelteKit 类似于 Next。如果您来自 Vue，SvelteKit 类似于 Nuxt。是个开箱即用的框架，包含了路由，热加载，SPA等功能。
  4. skeleton-是一个为 Svelte 和 Tailwind CSS 打造的现代化UI工具包。类似于(vue的ElementUI,react的and design pro)
  5. tailwindcss-是一个利用公用程序类（Utilize Class，下文皆称Utilize Class）的 CSS 框架。
  6. vite-新型前端构建工具(听说比webpack简单，webpack确实配置太难了)
  1. sveltekit
  2. skeleton

踩坑记录#

结论： 不能使用sveltekit2框架，因为它是开箱即用的web应用框架。使用它的路由功能（属于服务器端路由），它所使用的SSR（Server Sider Render）服务器端渲染需要有Nodejs环境。 但是Wails开发的客户端是纯的浏览器环境，是无法运行的。因此当你使用wails dev启动调试的时候，默认在后台启动了一个Nodejs环境，可以使用浏览器调试你的页面样式，程序能正常启动。 但是当使用wails build打包成exe可执行文件之后，由于缺少Nodejs服务器端渲染，程序是无法启动的。

搭建基础框架#

  1. 安装wails2,可以直接参照官方文档(https://wails.io/zh-Hans/docs/gettingstarted/installation)安装，此处不做详细介绍。当前项目安装的是wails2
  2. 使用wails2工具创建项目(sevlte5相较于3有很大改动)
1
2
3

# 这里我不用-t sevlte指定sevlte框架，直接创建一个空的项目（后续使用npm create vite@latest创建基于sevlte5的模板）
wails init -n myproject
# 默认使用-t sevlte 创建的项目使用的是sevlte3

踩坑开始#

3. 使用sv命令创建，sevlte/kit项目

1
2

cd myproject
npx sv create frontend  # 此处用frontend作为前端的项目名称与wails默认规则保持一致

备注： npm和npx的区别，npm 是 Node Package Manager（包管理器），npx 是 Node Package Execute（包执行器）。

npm: 安装管理包，下载并保存在本地

npx: 直接运行包，并不下载保存在本地

运行上述命令的时候，有一些选项需要我们自己指定 这里选择SvelteKit minimal，第三项的library是将SvelteKit作为库使用构建可发布的 Svelte 组件库、工具函数库，供其他项目使用 取决于自己需要用什么语言开发 这4个必选其他随意 两个插件的作用

typography (@tailwindcss/typography)

给富文本、文章、博客内容提供一套美观的默认排版样式 自动处理标题、段落、列表、代码块、引用等 HTML 元素的间距、字体和颜色 适合做内容型网站，不用自己写大量 prose 样式

forms (@tailwindcss/forms)

重置浏览器原生表单元素（input、checkbox、radio、select 等）的默认样式 让表单控件在不同浏览器下表现一致，并且更容易用 Tailwind 工具类自定义 适合做需要大量表单的后台管理、登录注册等页面
