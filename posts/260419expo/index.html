天下武功无坚不摧，唯快不破。快速开发React Native最佳选择。

为什么用Expo?#

使用@react-native-community/cli 创建的项目实在是太大了，本地需要安装完整的安卓开发环境。 如果都安装了完整的安卓开发环境，为什么不直接用Flutter直接开发，还要用React Native呢？ 我们就是要快，快，快。误信了React Native中文网的建议，浪费了大量的时间。使用Expo 10分钟就可以搞定。

Expo 是一个生产级别的 React Native 框架。Expo 提供了开发者工具，使开发应用更简单，如基于文件的路由、标准的原生模块库等。 开箱即用，快到起飞！两个对比如下：

名称耗时项目大小
Expo30分200Mb
react-native-community/cli2小时3G

https://reactnative.dev/docs/environment-setup

https://docs.expo.dev/

创建项目#

两者方式

1

npx create-expo-app@latest # 使用Expo
npx @react-native-community/cli init ProjName # 使用react-native cli

expo创建完项目，在安卓模拟器或手机上直接安装Expo GO即可直接运行。

如果安装Expo Go app下载速度慢可以直接进官网下载Expo对应版本的apk(使用的是github上)

EAS精简最小化打包项目#

Expo默认打包的项目是直接发布到谷歌商店的aab文件，文件体积大，谷歌商店最终文件小(在国内不适用)。

  1. 默认全架构： 打包 armeabi-v7a + arm64-v8a + x86，体积大
  2. 未压缩： Debug/Release 默认未开混淆、未瘦身
  3. 全量资源： 默认打包所有分辨率、语言包、无用依赖 正常空 Expo 项目：默认 APK ≈ 50–80MB；优化后可压到 15–30MB

APK 瘦身：从 80MB → 20MB（必做）#

  1. 架构精简（最有效）
  • 只保留 arm64-v8a、armeabi-v7a（国内 99% 手机）
  • 移除 x86、x86_64（模拟器 / 平板，商店不强制）
  1. 代码压缩（混淆）
  • 开启 minifyEnabled=true、proguard=true
  • 自动删除无用代码、缩短类名、压缩资源
  1. 资源优化
  • 图片：WebP、压缩、移除无用分辨率
  • 字体：只保留中文、英文
  • 依赖：删除无用包（如 react-native-web、测试库）
  1. Hermes 引擎（默认开启）

Hermes 是一个专门针对 React Native 应用而优化的开源 JavaScript 引擎。React Native 自带一个捆绑版本的 Hermes。

  • 启用 Hermes：体积更小、启动更快
  • app.json:
1
2

"ios": { "jsEngine": "hermes" }, # 已经不用配置了
"android": { "jsEngine": "hermes" }
