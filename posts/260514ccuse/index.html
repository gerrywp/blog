Claude Code CLI 如日中天，奈何 Opus 模型有额度限制且价格不菲。国产大模型中，智谱 AI（好用）和 DeepSeek（便宜）是首选，其他国产模型暂不推荐。

安装 Claude Code CLI#

全局安装：

1

npm install -g @anthropic-ai/claude-code

也可以使用智谱提供的 helper 脚本一键安装：

1

npx @z_ai/coding-helper

参考文档：

  • Claude Code 官方文档
  • 智谱 AI Coding Plan 文档

Codex 对接国产模型#

OpenAI 为其 Codex 和 Agents 生态推出了全新的 Responses API 协议（端点为 /v1/responses），用以替代传统的 Chat Completions 协议（端点为 /v1/chat/completions）。国产模型厂商（如 DeepSeek、智谱等）的 API 目前仍兼容旧协议，尚未跟进支持最新的 Responses 协议。因此，当 Codex 直接调用国产模型时，协议不匹配会导致请求失败。

解决思路是将 Responses 请求转换为 Chat Completions 格式。

方案一：Echobird（推荐）#

Echobird 是一个轻量级的 API 协议转换工具，部署后即可将 Codex 的 Responses 请求无缝转发到国产模型的 Chat Completions 端点。

安装与配置：

  1. 下载 Echobird（从 GitHub Releases 页面获取最新版本）。
  2. 配置后端 API 地址为目标国产模型的 Base URL 和 API Key。
  3. 启动 Echobird 服务（默认监听本地端口）。
  4. 在 Codex 中将 OPENAI_BASE_URL 指向 Echobird 的本地地址即可。

方案二：CCX（备选）#

CCX 是另一个优秀的开源协议转换工具，同样可以将 Responses 协议转为 Chat Completions 格式，用法与 Echobird 类似，可作为可靠的备选方案。

Codex 安装#

Codex 的安装主要有两种方式：直接从应用商店安装和离线安装。根据您的系统环境和需求，可以选择适合的安装方法。

1. 直接从应用商店安装#

这是最简单直接的安装方式：

  1. 打开 Microsoft Store
  2. 搜索 “OpenAI Codex”
  3. 点击 “获取” 或 “安装” 按钮完成安装

优点：

  • 安装过程简单，无需手动下载安装包
  • 自动获取最新版本
  • 自动处理更新

缺点：

  • 依赖微软商店服务
  • 在某些系统环境下可能无法正常安装

2. 离线安装#

当微软商店无法使用或双击 .msix 安装包失败时，可以采用离线安装方式：

2.1 下载 Codex 安装包#

  1. 打开解析站点：https://store.rg-adguard.net
  2. 在输入框中粘贴 Codex 的商店链接：https://apps.microsoft.com/detail/9PLM9XGG6VKS
  3. 右侧下拉框选择 “Retail”
  4. 点击查询，在返回结果中找到 Codex 对应的 .msix 文件下载链接
  5. 下载安装包到本地

注意：如果直接点击下载没反应，可以右键点击复制下载链接，然后在最前面拼上 https://

2.2 使用 PowerShell 安装#

  1. 打开 PowerShell（以管理员身份运行）
  2. 执行以下命令（将路径替换为实际的安装包路径）：
1

Add-AppxPackage -Path "C:\Users\用户名\Desktop\OpenAI.Codex_版本号_x64__包ID.Msix"

例如：

1

Add-AppxPackage -Path "C:\Users\52412\Desktop\OpenAI.Codex_26.415.3242.0_x64__2p2nqsd0c76g0.Msix"

2.3 验证安装#

安装完成后，可以通过以下方式验证：

  • 在开始菜单搜索 “Codex”
  • 查看是否出现 OpenAI Codex
  • 启动应用，确认能否正常进入主界面

参考文档：微软商店无法使用时，如何手动安装 OpenAI Codex？

Copilot 接入国产模型#

第一步：安装插件#

  • 安装 VS Code 的 GitHub Copilot 和 GitHub Copilot Chat 基础插件。
  • 在扩展商店搜索 “OAI Compatible Provider for Copilot”（或缩写 oai）并安装。此插件是让 Copilot 识别非官方模型的关键。

第二步：获取 API Key#

  1. 前往 智谱 AI 开放平台 注册并登录。
  2. 点击右上角头像 → API Keys → 创建新的 API Key。
  3. 复制生成的 Key 并妥善保存。

第三步：配置插件#

打开 VS Code 设置（Ctrl+,），搜索 oai，进入插件设置界面，填写以下信息：

Base URL（接口地址）：

服务商计费模式Base URL
智谱 GLMCoding Plan（包月）https://open.bigmodel.cn/api/coding/paas/v4
智谱 GLM按 Token 计费https://open.bigmodel.cn/api/paas/v4
DeepSeek—https://api.deepseek.com/v1
Kimi—https://api.moonshot.cn/v1

在 API Key 字段中粘贴你的 Key 并回车确认。

第四步：启用模型#

  1. 打开 Copilot Chat 面板（点击顶边栏 Copilot 图标，或快捷键 Ctrl+I）。
  2. 点击模型选择区域 → Manage Models（管理模型）。
  3. 在弹出的供应商列表中选择 [OAI Compatible]，点击右侧齿轮图标进入详细配置。
  4. 输入 API Key 并回车确认。
  5. 返回模型列表，勾选想使用的模型（如 GLM-5.1），点击 OK 保存。
  6. 在 Copilot Chat 的模型下拉菜单中将模型切换为 GLM-5.1，即可开始使用。
